# STM32F411CEU6 FreeRTOS, RTT, and EasyLogger Template

This project integrates FreeRTOS, SEGGER RTT, and EasyLogger as a development baseline for future projects. TIM1 provides the HAL time base. Standard `printf` and EasyLogger logs use RTT channel 0. CMSIS V2 initializes and starts the FreeRTOS kernel, while application tasks are created through native FreeRTOS APIs.

## Task Organization

- Resource creation is centralized in `Z02_Business/Init/os_init.c` and `os_init.h`. The generated `Core/Src/freertos.c` calls `OS_Init()`, and the default `osThreadNew(...)` creation statement is commented out. Create future tasks and other RTOS resources in `OS_Init()`.
- Each task has its own directory with matching `.c/.h` files. `Z02_Business/Status_Task` tests LED blinking and logging through `Z01_BSP/LED`. It toggles the LED and writes a status log every 500 ticks, approximately 500 ms at the current 1000 Hz tick rate.
- Remove the status test task when it is no longer needed, along with its include, creation code in `os_init.c`, and Keil references.

## Usage

Open `MDK-ARM/STM32F411CEU6.uvprojx` in Keil MDK-ARM with ARMCC 5, build and flash the target, then view channel 0 in J-Link RTT Viewer. Check that the LED toggles periodically and status logs appear.

The current baseline builds with ARMCC V5.06 update 7 (build 960) with **0 errors and 0 warnings**, and runtime testing has passed.

## Regenerating Code with CubeMX

**Back up the project before every configuration change.** The current configuration uses STM32CubeMX 6.16.1 and STM32Cube FW_F4 V1.28.3. Regeneration may restore or overwrite manual changes. Afterwards:

1. Comment out the default task's `osThreadNew(...)` creation statement in `Core/Src/freertos.c` again, keeping the `os_init.h` include and `OS_Init()` call.
2. Retain the TIM1 HAL time base and CMSIS V2 kernel initialization and startup.
3. Check that `debug_init()` and `LED_Init()` in `main.c`, and the RTT `fputc()` redirection in `usart.c`, remain intact. Verify the Keil groups, source files, and header search paths for RTT, EasyLogger, Z01, and Z02.
4. Use the FreeRTOS kernel generated by CubeMX; there is no need to restore an older kernel directory after generation.
