# STM32F411 Bootloader: YMODEM CRC and Encrypted Firmware Installation

## Project Description

##### Introduction

This is the Bootloader subproject of [project 046](../../README.md), using the STM32F4 standard peripheral library. It receives encrypted firmware or uses a package downloaded by an APP, then decrypts, installs and launches the application.

##### Main Features

- Check YMODEM packet types, sequence complements and CRC-16/XMODEM before writing to external region A.
- Decrypt A into B with AES-256 CBC; validate image length and startup vectors, back up a valid old APP and install the new APP.
- Select startup/update paths from EEPROM states `0x00`, `0x11` and `0x22`.
- Retain transfer/storage length checks; CRC covers each frame's data area including padding, not the entire file.

##### Repository Structure

```text
Core/, Drivers/     Peripheral initialization and SPL/CMSIS
BSP/, SYSTEM/       External storage, GPIO and delay support
Middlewares_User/   YMODEM, CRC, AES, logging and RTT
Tasks/Bootloader/   State management, decryption, installation and launch
MDK-ARM/            STM32F411CEU6_SPL.uvprojx
```

## Usage Guide

##### Environment and Dependencies

STM32F411CEU6, W25Q SPI flash, AT24C02 EEPROM, USB-to-UART and J-Link; Keil MDK 5.38 / ARMCC 5.06 update 7, SecureCRT or another YMODEM sender, and RTT Viewer. SPL/CMSIS, libcrc, AES, EasyLogger and SEGGER RTT are included.

##### Hardware Connection and Configuration

Use 3.3 V logic and a common ground; cross-connect UART TX/RX.

| Interface | Configuration |
|---|---|
| USART1 | PA9 TX / PA10 RX; 115200 baud, 8N1, no flow control |
| W25Q SPI1 | PA4 CS / PA5 SCK / PA6 MISO / PA7 MOSI |
| AT24C02 software I2C | PB8 SCL / PB9 SDA; retain bus pull-ups |
| Status and input | PC13 LED; PA0 active-low key |

Bootloader: `0x08000000`, 32 KiB. APP run region: `0x08008000`, 96 KiB. External A/B: `0x000000–0x00FFFF` / `0x010000–0x01FFFF`, each 64 KiB.

##### Build, Run, and Observe

1. Build `MDK-ARM/STM32F411CEU6_SPL.uvprojx`. Build [APP1](../02_APP1/README.md) at `0x08008000` and encrypt its latest BIN using the matching AES-256 CBC format/key/IV. Packages must exceed 16 bytes, be 16-byte aligned and fit in 64 KiB.
2. For a fresh installation, clear EEPROM OTA state at `0x00` to `0x00`, erase all MCU internal flash and flash Bootloader. External flash and EEPROM survive chip erase.
3. Wait about 13 seconds, press the key to request download, then send `../04_BIN_EncryptionBIN/APP1_EncryptionBIN.mxxx` (generated by rebuilding) by YMODEM when `C` is received.
4. Observe `APP installed … Launching APP` and `App1 running...` in RTT. A first installation has no valid old APP to back up.
5. For an APP-initiated update, the APP downloads the package and commits state `0x22`; after its update command/key confirmation, reset enters Bootloader to install the stored package. See [APP1 instructions](../02_APP1/README.md).

Both first installation and the APP1 → APP2 update passed the 2026-10-07 hardware test. CRC-mismatch injection and failure rollback were not tested in this run. If logs disappear after launch, reconnect RTT Viewer and search for the new control block.

##### Porting Notes

Adapt SPL peripherals, clocks, flash sectors, image/vector address checks, EEPROM metadata and external partitions. Keep APP addresses and AES parameters consistent with the companion APPs and packaging tool.
