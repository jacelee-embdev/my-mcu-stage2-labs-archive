# STM32F411 FreeRTOS 中断响应时间优化试验

## 项目说明

本工程用于检测并优化按键外部中断处理路径的响应时间。优化对象是 ISR 与按键任务之间的内部边沿事件队列：原方案在队列发送和接收时复制完整的 `key_press_event_t`，优化方案只传递事件对象指针，从而减少大结构体的复制开销。工程保留两套完全独立的 `.c/.h` 实现，通过一个配置开关切换，便于在相同工程和测试条件下进行对照试验。

## 试验设计

KEY1 按下时，PA0 由高电平变为低电平并触发 EXTI0。ISR 构造边沿事件并调用 `xQueueSendFromISR()`，随后在处理路径末端翻转 PB12 测试引脚。逻辑分析仪同时采集 PA0 与 PB12：

```text
T_response = t(PB12 翻转) - t(PA0 下降沿)
```

该区间包含异常进入、HAL 回调、事件准备、队列发送、GPIO 配置及标记引脚操作，是本工程定义的端到端中断处理路径时间，并非处理器的纯异常入口延迟。PB12 在队列发送后翻转，因此表中数据直接体现 ISR 发送侧的差异；任务侧接收同样只复制指针，但不在本测量窗口内。

## 模式切换与优化方式

总开关位于 `BSP/key/inc/bsp_key_config.h`：

```c
#define BSP_KEY_QUEUE_POINTER_MODE    0U
```

- `0U`：使用 `bsp_key_queue_value.c/.h`，队列复制完整事件对象；
- `1U`：使用 `bsp_key_queue_pointer.c/.h`，队列只复制事件对象指针。

两组文件均加入 Keil 工程，并由条件编译保证每次只有一组生效；`Core/Src/freertos.c` 也根据同一开关包含相应头文件。本优化只针对内部队列 `s_key_edge_queue`，公开按键队列 `g_key_queue` 仍传递 `key_event_t` 值。

## 测试结果

| 测试情况（结构体总大小） | 传值 | 传指针 | 降低量 | 降低率 | 平均每 Byte 降低 |
|---|---:|---:|---:|---:|---:|
| 基准：注释掉数组（8 Byte） | 10.85 µs | 10.85 µs | 0 µs | 0% | 0 |
| `uint32_t test_payload[32]`（136 Byte） | 20.40 µs | 10.85 µs | 9.55 µs | 46.81% | 0.0746 µs/Byte |
| `uint32_t test_payload[64]`（264 Byte） | 29.30 µs | 10.85 µs | 18.45 µs | 62.97% | 0.0695 µs/Byte |
| `uint32_t test_payload[100]`（408 Byte） | 39.40 µs | 10.85 µs | 28.55 µs | 72.46% | 0.0701 µs/Byte |

结构体越大，传指针的收益越明显：408 Byte 时延迟降低 28.55 µs，降低率为 72.46%。基于本次 PC、逻辑分析仪、MCU 和软件配置，结构体每增加 1 Byte，传指针相较传值平均约减少 **0.071 µs**。该数值只描述本次数据的变化趋势，不是跨平台固定指标。

## 测试平台与约束

| 项目 | 配置 |
|---|---|
| MCU / 时钟 | STM32F411CEU6（Cortex-M4F），100 MHz |
| 软件 | STM32 HAL，FreeRTOS V10.3.1 |
| 工具链 | Keil MDK-ARM 5，ARM Compiler 5.06 update 7（build 960），O3 |
| 固件包 | STM32Cube FW_F4 V1.28.3 |
| 测量区间 | PA0 输入下降沿至 PB12 测试标记边沿 |

结构体大小受编译器 ABI、枚举宽度和内存对齐影响。结果还会受到芯片与主频、编译优化、FreeRTOS 和中断负载、逻辑分析仪采样率与触发阈值、探头接线以及调试器状态影响。复测时应保持上述条件一致，并记录测试次数、最小值、最大值和平均值。

## 复现与已知限制

将逻辑分析仪连接 PA0、PB12 和 GND，在两套头文件中设置完全相同的 `test_payload` 长度，分别选择 `0U` 和 `1U` 后完整编译、下载并多次测量。当前传指针版本复用一个静态事件对象；若旧事件尚未处理就发生新边沿，多个排队指针可能指向同一份已更新数据。因此它适合受控性能试验，不应直接用于高并发生产场景；正式应用应改用静态对象池或具有明确所有权的缓冲机制。
