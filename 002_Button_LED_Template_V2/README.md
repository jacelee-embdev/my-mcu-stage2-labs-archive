# STM32F411CEU6 Button LED Control (Custom Template V2)

This project records button-controlled LED operation in a custom HAL template, separating the application entry point, board drivers, and system support code. The main program is in `Users/main.c`, the button and LED drivers are in `Drivers/BSP`, and the clock, delay, and UART support modules are in `Drivers/SYSTEM`.

## Implementation and Behavior

PA0 is a pull-up input, with the button connecting it to ground when pressed. PC13 is a push-pull output. The main loop calls `key_is_pressed()` to detect a low level, calls `led_toggle()` when the condition is met, then blocks for approximately one second. Holding the button toggles the LED repeatedly; a short press during the delay may be missed. Separate debounce logic and single-press detection can be added later.

The system runs directly from the internal 16 MHz HSI. The delay functions poll SysTick using counts configured for 16 MHz; review the delay parameters whenever the clock changes. The current entry point initializes the clock, LED, and button. The UART driver is retained as a support module.

## Build and Use

1. Open [STM32F411CEU6.uvprojx](Projects/MDK-ARM/STM32F411CEU6.uvprojx) in Keil MDK, using ARMCC 5.06 update 7 and STM32F4xx_DFP 2.17.1.
2. Rebuild the project and download it through SWD. Connect the button between PA0 and ground, check the PC13 LED wiring, and observe the response to holding and briefly pressing the button.
3. Continue extending the entry point and BSP drivers as needed. The current SCT is retained in `Output`; build outputs are generated by rebuilding the project.
