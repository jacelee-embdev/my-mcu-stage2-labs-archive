# 外设数据写入与功能测试示例

## 项目说明

##### 项目简介

本仓库包含两个独立裸机工程：01 向用户 EEPROM 写入应用 AES 密钥和初始向量 IV，02 验证外设功能及存储页读写。两者均通过 RTT 输出结果。

##### 主要功能

- 写入应用 AES-256 密钥和 IV，读回后检查 CRC 与完整页数据。
- 验证通信、认证、加解密回环，提供存储写读和只读两个测试入口。
- 记录底层错误，区分数据匹配、实际失败、未确认结果及库范围限制。

##### 仓库结构

```text
01_Key_data_burning/                   应用密钥与 IV 烧录
02_Chip_function_test_demonstration/   外设功能与存储范围测试
LICENSE                               仓库许可证
```

详细说明：[01 子工程](01_Key_data_burning/README_zh.md) · [02 子工程](02_Chip_function_test_demonstration/README_zh.md)。

## 工程使用指南

##### 环境与依赖

各子工程配套开发板、外设、驱动与静态库，Keil MDK 5（ARM Compiler 5）、J-Link 及 RTT Viewer。

##### 硬件连接与配置

通过 SWD 连接调试器。外设按所选子工程配置接线并共地，I2C 信号线需上拉；运行前核对测试模式与写入参数。

##### 编译、运行与观测

1. 按用途选择 01 或 02 子工程，打开其 `MDK-ARM/` 中的 Keil 工程。
2. 编译、下载并复位运行；两个子工程分别编译和使用。
3. 在 RTT Viewer 的 Terminal 0 保存完整日志，按子工程说明判断结果。

01 默认写入页 0，每页 64 字节，每次启动都会再次尝试烧录；`SUCCESS` 表示本次写入及读回校验通过。

02 请求页号 0～35，共 2304 字节；现有库允许访问 0～29 页，共 1920 字节。后六页的 `SDK_LIMIT` 表示库拒绝且未实际访问芯片，不能作为硬件容量边界。最近完整写读与只读日志中，30 个用户页均匹配。

写入会覆盖原数据，02 包含 01 使用的页 0。验证断电保存时，烧录只读版本后真正断电，再上电只读核对，期间不得重写。数据匹配不能单独确定物理容量、具体型号或丝印是否正确。

##### 移植说明

移植时核对 BSP 引脚、延时、接口及静态库兼容性，更新头文件搜索路径和链接配置，并确认外设支持所用存储接口。
